# Twitter Blue Bird Restorer 🐦

Chrome・Edge・BraveでXのロゴや表示名をTwitter風に変更する拡張機能です。投稿本文、ユーザー名、プロフィール、入力中の文章は変更しません。

## インストール

**Windows用の自動セットアップキットを利用する場合**は、リポジトリのトップページにあるREADMEを参照してください。

拡張機能だけ使いたい場合は、各ブラウザの拡張機能画面（`chrome://extensions`、`edge://extensions`、`brave://extensions`）でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から、このフォルダを選びます。

拡張機能はWebサイト内の見た目を変えます。Windowsのタスクバーやインストール済みアプリアイコンを変えるには、別途Windows向けセットアップキットが必要です。

X公式の拡張機能ではありません。
