# Twitter Blue Bird Restorer 🐦

**v1.3.1（Windows/BraveネイティブPWA名・アイコンの変更用キット付き）**

x.comの公式Xロゴを青いTwitterの鳥に置き換え、公式UIのブランド名をTwitterに変更します。投稿本文、ユーザー名、プロフィール、入力欄などは変更しません。


## v1.3.1: インストール後にタイトル先頭のXとWindowsアイコンが残る場合

WindowsのPWAタイトル先頭とタスクバー・デスクトップのアイコンはBraveが
Windowsに登録したアプリ情報で決まります。拡張機能のDOM置換だけでは変更できません。

Windows用の `windows-policy/` に、Braveが対応している
`WebAppInstallForceList` ポリシーで **アプリ名 Twitter / 青い鳥アイコン** を指定する
スクリプトと解除用スクリプトを同梱しました。

**v1.3.1:** `windows-policy/Start-Twitter-Setup.cmd` をダブルクリックして起動してください。
終了時やエラー時に画面が閉じず、原因が表示されます。復元は `Start-Twitter-Rollback.cmd` から行えます。
`.ps1` の直接ダブルクリックや「PowerShellで実行」は、エラーが読めずに閉じるため避けてください。
実際に落ちた原因は、エラー表示を確認するまで特定できません。

**これは任意の上級者向け手段です。** ポリシー有効中はTwitterが強制インストールとなり
Braveの通常のアンインストールができなくなります。またWindowsユーザー内の
他のBraveプロファイルにも適用され得ます。`windows-policy/README.txt` を読み、
事前に以前のXアプリを `brave://apps` からアンインストールして使用してください。
スクリプトは既存ポリシーの上書きを禁止し、解除ツールを同梱しています。

ページの `<meta name="application-title">` も追加し、アプリがTwitterという名前に
登録された際に「Twitter - Twitter - ホーム / Twitter」と重複しないようにしました。
このメタタグだけでは既存PWAのアプリ名「X」を変更できません。

実機のBrave/Windowsでポリシー適用までの動作確認はできていません。

## v1.2.0の追加点

従来の表示変更に加えて、x.comのWebアプリ（PWA）としてインストールする際の情報を差し替えるため、`<link rel="manifest">` に拡張機能内のPWAマニフェストを優先指定します。これにはアプリ名 `Twitter`、短縮名 `Twitter`、青い鳥の192/512pxアイコンを設定しました。既存のサイトマニフェストは削除しません。

**重要：この機能は試験的です。** PWAのインストール画面はBraveが管理します。サイトのCSPやBrave側の仕様によって、拡張機能が指定したマニフェストが拒否されることがあります。マニフェストの読み込みエラーが通知される場合には差し替えリンクを取り除いてサイト本来の設定に戻します。実際のx.com上でインストール画面がTwitterになることはまだ検証できていません。アプリ名が `X` のままなら、上書きできていません。

`x.com` はサイトのドメイン名なので、インストール画面のドメイン表示はそのまま残ります。

## インストール・更新（Brave）

1. ZIPを解凍する。
2. `brave://extensions` を開き、以前の版の本拡張機能を削除する。複数の版を有効にしないこと。
3. 「デベロッパーモード」をONにし、「パッケージ化されていない拡張機能を読み込む」から、`manifest.json` があるフォルダを選択する。
4. 新しいブラウザタブで `https://x.com/home` を開く。ページ内の青い鳥とTwitter表記を確認する。
5. アプリのインストール画面を開く。「Twitter」と青い鳥に変わっている場合はインストールする。`X` のままならインストールを中断する。
6. すでにXのWebアプリ（PWA）がインストールされている場合は、`brave://apps` で古いアプリをアンインストールしてからインストールし直す（個別アプリのデータ保持についてはBrave側の選択を確認）。

### 変更されなかった場合

ページの `F12` → `Application`（アプリケーション）→ `Manifest` にあるアプリ名・アイコンを確認する。Brave側が元のサイトマニフェストを使用している場合は、この方式では変更できません。Chrome/Braveの設定画面やインストールダイアログはサイトの外側にあり、通常のコンテンツスクリプトでは直接変更できません。

その場合は別途作成した `twitter-brave-launcher` のショートカット方式を使うと、「Twitter」名・鳥アイコンのショートカットを作れます。ただしWindowsタスクバー等のPWA管理部分の完全な置換は保証できません。

## 従来からの機能

- ナビゲーションの公式Xロゴ → 青い鳥
- 公式UIの `X` / `About X` 等の既知ラベル → `Twitter` / `About Twitter`
- favicon → 青い鳥
- ページタイトル末尾の `/ X` → `/ Twitter`
- ホーム等のブランド用タイトル先頭の `X -` → `Twitter -`
- 投稿/引用/ユーザー名/プロフィール/入力は変更しない
