# Twitter Blue Bird Restorer 🐦

X（x.com）を、青い鳥の「Twitter」の見た目に戻すWindows用ツールです。**Chrome / Edge / Brave** に対応します。ツイート本文、ユーザー名、プロフィール、入力中の文字は書き換えません。

## インストール

1. [最新のリリース](https://github.com/p1-10r/x-to-twitter-restorer/releases/latest) から `twitter-restorer-kit.zip` をダウンロードして解凍します。
2. ZIPに同梱されている版を使用する場合は `Start-Twitter-Setup.cmd` をダブルクリックします。GitHubの最新版を取得する場合は `Start-Twitter-Bootstrap.cmd` を使います。
3. Windowsの管理者確認が表示されたら、変更内容を確認して承認してください。
4. 既定ブラウザを自動検出します。対象外の場合は Chrome / Edge / Brave から選択できます。
5. 画面に表示された変更内容を読み、同意する場合に `REINSTALL` と入力します。
6. **拡張機能がすでに有効か自動確認**します。入っていない場合のみ、表示された拡張機能画面でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から画面に表示されたフォルダを指定してください。Enterで登録状態を再確認します。
7. 既存のTwitter/Xアプリがあればアンインストール確認が出ます。「閲覧データも削除」を選ばないでください。青い鳥のアプリを再登録し、デスクトップショートカットを作成します。タスクバー固定にはWindowsの操作が必要な場合があります。

> ブラウザの拡張機能の初回読み込みは、ブラウザの許可画面が必要です。自動セットアップでも無断で登録することはできません。

## 変更されること

- x.com内の公式ロゴ、favicon、サービス名の表示、タイトル
- WindowsのPWA登録ポリシー (`WebAppInstallForceList`)、デスクトップ・タスクバーのショートカット
- 毎日の拡張機能更新確認タスク（最新版を確認し、ブラウザの再読み込みが必要になる場合があります）
- PWA/ショートカットに使用する青い鳥アイコンは、背景透過の画像です。

変更前に画面で確認を求めます。Cookie、サイトデータ、ログイン情報、閲覧履歴を削除する処理は行いません。既存PWAを削除するときも、ブラウザの閲覧データ削除を選択しないでください。

## 再起動のたびにデスクトップのTwitterアイコンが増える場合

以前のバージョンでは、ブラウザの `WebAppInstallForceList` にデスクトップショートカットを毎回作る設定が含まれていました。現行版ではブラウザ側の生成を無効にし、Twitter Restorerが作った1個のショートカットを再利用します。

**すでにTwitterがインストールされている場合は、再インストール不要。** 同梱の `Start-Twitter-Stop-Duplicates.cmd` を実行し、内容を読んで `FIX` と入力してください。設定変更前に対象のブラウザと重複ショートカットを表示します。ブラウザのTwitterアプリ・拡張機能・サイトデータは変更しません。

この修復では、所有確認ができたTwitter用ポリシーの `create_desktop_shortcut` を `false` に変更します。元の `Twitter.lnk` は残し、**同じブラウザ・同じアプリ起動引数の** `Twitter (2).lnk` など、数字付き複製だけを `%LOCALAPPDATA%\TwitterBlueBirdRestorer\DesktopShortcutBackups` に移動します。別のブラウザのショートカットやほかのPWAはそのままです。変更後に対象ブラウザを完全に終了し、再起動してポリシーを読み直してください。

## よくある質問

**拡張機能が未登録と表示される**：拡張機能の管理画面で有効でも、ブラウザの登録情報がディスクに未保存だったり、別プロファイルに保存されていることがあります。表示される拡張機能の状態を確認してください。`Start-Twitter-Diagnostics.cmd` は保存されている `state` が `0`、`1`、項目なしのどれかも表示します。`state` がない場合でも拡張機能の登録先・バージョンが一致して明示的な無効記録がなければ、インストール済みと推定して処理を進めます。ブラウザ上のON状態を直接確認したわけではないため、表示が戻らない場合は拡張機能管理画面を確認してください。画面ではONなのに保存状態が違う場合、Braveを完全終了して診断をやり直してください。設定ファイルは書き換えません。

**拡張機能がインストールされない**：`chrome://extensions` / `edge://extensions` / `brave://extensions` で「Twitter Blue Bird Restorer」が有効か確認してください。Windowsユーザーのブラウザプロファイル単位で登録が必要です。

**デスクトップのTwitterアイコンに白い丸が残る**：`Start-Twitter-Desktop-Icon-Fix.cmd` を実行してください。16〜256pxの複数解像度を持つ透過ICOを新しいファイル名で保存し、Windowsへアイコン更新通知を送信します。実行ログの `after:` に新しい `.ico` が表示されることを確認してください。**PWAや拡張機能の再インストールは不要**です。新しいICOが参照されているのに白背景が残るときは、Windowsのアイコンキャッシュを疑い、サインアウトして戻ってください。

**タスクバーのアイコンが古いまま**：古いピン留めを解除し、Twitterを起動してからピン留めし直してください。ブラウザ自身が保持するPWAアイコンにはWindowsのキャッシュが使われることがあります。

**拡張機能を認識しない**：Default以外のブラウザプロファイルも自動確認し、登録元フォルダと有効状態も照合します。ブラウザがディスクへ設定を書き込む前など、完全に自動検知できない場合はあります。再インストールを繰り返さず、`Start-Twitter-Diagnostics.cmd` を使ってプロファイル・拡張機能の登録状況を確認してください。診断は設定を変更しません。

**古い版がダウンロードされた**：GitHubのリリース公開が遅れている場合、Bootstrapは古いインストーラーで上書きせず停止します。ダウンロード済みの新しいZIPに含まれる `Start-Twitter-Setup.cmd` を使用するか、GitHubの最新版公開を待って再試行してください。

**PowerShellが即終了する**：`.ps1` を直接ダブルクリックせず、同梱の `Start-Twitter-Setup.cmd` または `Start-Twitter-Bootstrap.cmd` を実行してください。

**完全アンインストール**：`Start-Twitter-Uninstall-All.cmd` を実行します。ポリシーと自動更新タスクを解除したあと、ブラウザ側に残った拡張機能は**手動で「削除」**してください（OFFにするだけでは削除されません）。拡張機能を削除できたと確認してから専用フォルダやショートカットを整理します。詳しい手順は次の「アンインストール手順」を参照してください。Cookie・ログイン情報・サイトデータは削除せず、元のX PWAも自動再作成しません。`Start-Twitter-Remove.cmd` も互換用として完全アンインストーラーを起動しますが、分かりやすい `Start-Twitter-Uninstall-All.cmd` の使用をおすすめします。

## 完全アンインストール手順（拡張機能が残っている場合）

1. `Start-Twitter-Uninstall-All.cmd` をダブルクリックし、対象を確認して `UNINSTALL` と入力します。
2. **Brave** はアドレスバーに `brave://extensions`、**Chrome** は `chrome://extensions`、**Edge** は `edge://extensions` と入力して管理画面を開きます（使っていたブラウザすべて）。
3. 一覧から **Twitter Blue Bird Restorer** を探し、カードの **「削除」(Remove)** → 確認ダイアログの **「削除」** をクリックします。**有効/無効のスイッチをOFFにするだけでは不十分**です。
4. ブラウザ右上のプロフィール切り替えから、利用していた**すべてのプロファイル**で同様に確認・削除してください。管理画面を再読み込みし、拡張機能のカードが消えたことを確認します。
5. 併せて `brave://apps` / `chrome://apps` / `edge://apps` にある、今回のツールが導入したTwitter PWAを削除します。**閲覧データ・サイトデータを削除する選択肢はチェックしない**でください。
6. ブラウザを完全に終了し、CMDに戻って `REMOVED` と入力します。残っている登録が検出された場合は完了扱いにならないので、再度ブラウザの管理画面で削除してからCMDを実行し直してください。

**拡張機能の「削除」が押せない場合：** 本ツールが所有するPWAポリシーを解除してからブラウザを再起動し、管理画面を開き直してください。会社や学校など第三者管理のポリシーは本ツールでは解除しません。`Preferences` / `Secure Preferences` を手で編集したり、拡張機能のファイルだけを先に消したりしないでください。

**検出が0件でもブラウザに拡張機能が見える場合：** 自動検出はブラウザの保存状態によって漏れることがあります。CMDには手動確認手順が表示されるので、上記のURLで実際にカードが消えたことを確認してください。

## v1.5.18について

完全アンインストール時、Brave/Chrome/Edgeに拡張機能が残る場合に備え、各ブラウザとプロファイルでの**手動削除（削除ボタン → 確認）**をCMDとREADMEの両方で案内するようにしました。自動検出が0件でも、専用ファイルが残る場合は手動確認を求めます。ブラウザの設定ファイルやサイトデータは直接変更しません。
